# Thuis — pitch demo

Elderly-first Dutch UI for a Policy Hackathon concept: scripted digital help under a human DigiD Machtigen holder. Not an official Collabotics product.

## Run

```bash
cd C:\Users\MatKa\Projects\thuis
npm install
npx vite --host 127.0.0.1 --port 5173
```

Open http://127.0.0.1:5173/

## Demo flow

Home → **Afspraken bekijken** or **Hulp bij een taak** → domain → organisation → task → confirmation (human holds DigiD machtiging; Stop/Annuleren) → started.

## Colours

From collabotics.com logo/SVG accents: `#3590EC`, `#D1EBFF`, `#B6DFFD`, `#0C7281`, `#25A428` on a light paper surface for readability.
